# Analog Clock

## Project Overview

This project is an analog clock developed using HTML, CSS, and JavaScript. The clock visually represents the current time with hour, minute, and second hands, providing a functional and stylish way to tell time. The design is responsive and adjusts to different screen sizes.

## Features

- **Real-Time Clock**: Displays the current time and updates every second.
- **Stylish Design**: Utilizes CSS to create an attractive and modern clock face.
- **Responsive Layout**: The clock adjusts to fit various screen sizes and orientations.
- **Customizable**: Easy to modify styles and functionality according to personal preferences.

## Technologies Used

- **HTML**: For the structure of the clock interface.
- **CSS**: For styling the clock, including the clock face and hands.
- **JavaScript**: For updating the time dynamically and controlling the movement of the clock hands.
